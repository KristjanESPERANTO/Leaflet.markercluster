Leaflet.markercluster performance benchmark

This page measures marker creation and clustering separately with 100,000 markers. The final run remains visible on the map so you can inspect the resulting clusters.

Build the project first, serve the repository through a local web server, and open this file in a browser. Use the same browser, build, dataset, zoom level, and number of runs for before-and-after comparisons. Tile loading is not included in the clustering measurement.
